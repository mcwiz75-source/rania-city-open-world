# RANIA CITY – OPEN WORLD

An original mobile-first 3D open-city action game prototype.

## Current playable features
- 3D city blocks, roads, trees and buildings
- Original stylised player character
- Drivable red car with enter/exit interaction
- Touch controls and keyboard fallback
- First exploration mission with a reward
- Android APK build through GitHub Actions

## Build
Push to `main` or run **Build RANIA CITY Android APK** manually from the Actions tab. Download the artifact named **RANIA-CITY-Android-APK** when the workflow succeeds.

## Notes
This is the first playable prototype, not a finished AAA-scale game. More missions, detailed character animations, traffic, sound, interiors, save data and performance tuning will be added in later versions. Visual quality and frame rate depend on the Android device.
